# Security Policy — CyberShield AI

## Reporting Vulnerabilities
We take the security of CyberShield AI and our users very seriously. If you discover a security vulnerability, please report it responsibly.

- **Email:** `security@cybershield.ai`
- **PGP Key:** Available upon request.
- **Response Time:** We acknowledge receipt within 48 hours and provide a remediation timeline.

## Supported Versions
Only the latest stable release of CyberShield AI receives security updates.

## Safe Usage Disclaimer
CyberShield AI is a consumer safety and scam-awareness assistant. It provides heuristic risk scoring and educational guidance but cannot guarantee 100% detection of all online threats or malicious actors. Always exercise independent caution online.
